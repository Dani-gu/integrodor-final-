01 · Necesidad

Planificar sin anticipar la demanda es difícil

Una decisión de producción empieza con una pregunta:
¿cuánto podríamos vender?

Producir de menos puede dejar pedidos sin atender. Producir de más puede inmovilizar materia prima y producto terminado.

El pronóstico no reemplaza la experiencia del equipo: agrega una referencia cuantitativa para decidir qué revisar antes de producir.
El problema que aborda el módulo02 / 10

06 · Validación temporal

Para medir, se respeta el orden de las fechas

El modelo aprende con meses pasados. Después se contrasta con un mes que todavía no había visto.

Meses pasados · entrenamientoMes posterior · validación
ENTRENARUsar únicamente la historia disponible
PRONOSTICAREstimar el mes siguiente
COMPARARRevisar contra el valor observado
REPETIRAvanzar en el tiempo y medir otra vez
La separación temporal evita que meses futuros filtren información al entrenamiento. La base demostrativa sirve para revisar el proceso; no basta para demostrar precisión operativa.

07 · Métricas

El error se expresa en unidades y porcentaje

Pronóstico: 420 unidades   ·   Venta observada: 390 unidades
MAE

Error absoluto medio

En este ejemplo, la diferencia es 30 unidades. El MAE promedia diferencias absolutas.

RMSE

Error cuadrático medio

También está en unidades y castiga más los errores grandes.

MAPE

Error porcentual

En el ejemplo, 30 ÷ 390 ≈ 7,7%. No se interpreta igual cuando la venta es cero.

Cifras didácticas, no métricas verificadas del prototipo. Una métrica más baja solo es útil si se calcula sobre datos que el modelo no utilizó para aprender.
