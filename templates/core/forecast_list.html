¿CÓMO SE CALCULA?

Cómo interpretar el pronóstico

01

Usa el historial disponible

Combina las ventas registradas en el sistema con el historial importado. Para calcular un producto necesita {{ history_months_required }} meses completos.

02

Compara tres métodos

Random Forest combina 200 árboles de decisión para reconocer patrones recientes y estacionales. También se evalúan la media móvil de 3 meses y el suavizado de Holt; se selecciona el que tuvo menor error al comparar estimaciones pasadas con ventas registradas.

03

Proyecta 12 meses

La cantidad es una estimación de unidades que podrían venderse en cada uno de los próximos 12 meses; sirve para planificar, no representa una venta confirmada.

MAE: error promedio en unidades; más bajo suele indicar una estimación más cercana.

RMSE: también mide el error en unidades y penaliza más los errores grandes.

MAPE: error porcentual; se muestra como “—” si los meses de validación no tuvieron ventas reales.
