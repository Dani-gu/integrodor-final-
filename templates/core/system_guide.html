FLUJOS DE TRABAJO

Cómo presentar una operación

Registrar y cobrar una venta

  1. Selecciona el cliente y los productos.
  2. Guarda la venta; se comprueba el stock y se registra la salida.
  3. Registra el pago completo o parcial y su forma: efectivo, transferencia o QR.
  4. Abre el comprobante de venta para imprimirlo.

Fabricar un producto

  1. Configura las materias primas y la receta del producto.
  2. Crea el lote con cantidad planificada, máquina y operario.
  3. Inicia el lote y, al terminar, registra cantidades reales.
  4. El sistema suma el producto terminado, descuenta materiales y deja los movimientos visibles en el detalle del lote.

MACHINE LEARNING

Cómo explicar el pronóstico

El sistema agrupa las ventas por mes y producto, compara métodos de estimación y muestra el resultado junto con su error histórico cuando hay datos para calcularlo. Un pronóstico bajo o igual a cero puede indicar ventas escasas o irregulares en los datos disponibles; no se debe interpretar como una orden de producir cero.

Para mejorar la estimación, registra las ventas reales correctamente y revisa el período y el producto consultados.
